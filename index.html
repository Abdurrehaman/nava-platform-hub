### NAVA PLATFORM HUB — Autonomous AI Cloud & Telemetry Console
Tech Stack: JavaScript (ES6+), HTML5 Canvas, Telemetry APIs, vLLM & DCGM Metrics, InfiniBand/RoCEv2

• Architected an enterprise-grade AI-native GPU cloud console for real-time fleet monitoring, inference engine benchmarking, and self-healing infrastructure operations.
• Engineered live telemetry dashboard tracking vLLM, SGLang, and TensorRT-LLM serving engines; visualized Time-To-First-Token (TTFT), Inter-Token Latency (ITL), and KV-Cache paging.
• Implemented bare-metal SRE observability module integrating NVIDIA DCGM hardware metrics and real-time Xid error detection (e.g. Xid 79) with automated node isolation runbooks.
• Visualized high-throughput GPU backend network fabric (RoCEv2, InfiniBand, GPUDirect RDMA) over Leaf-Spine topology with PFC/ECN congestion management alerts.
• Developed an interactive AI Workload Flight Simulator to benchmark FP8/AWQ quantization performance and speculative decoding (EAGLE) speedups before cloud deployment.
