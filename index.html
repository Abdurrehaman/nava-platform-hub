### NAVA GPU SRE SENTINEL — Autonomous Fleet Reliability & Self-Healing Platform
Tech Stack: Python 3, FastAPI, SQLite, SQLAlchemy, REST APIs, JavaScript (ES6+), HTML5 Canvas, Docker

• Built a full-stack bare-metal GPU fleet observability and automated remediation platform targeting hyperscale AI clouds.
• Engineered Python FastAPI backend REST APIs providing real-time hardware telemetry ingestion, NVIDIA DCGM metrics, and kernel error logging.
• Developed an automated self-healing background worker in Python to detect Xid 79 hardware failures (GPU PCIe bus loss), execute node cordoning, and trigger automated pod eviction runbooks.
• Implemented an interactive single-page dashboard with real-time hardware metrics (SM occupancy, thermal draw, PCIe bandwidth) and an API inspection log.

🎯 2-Hour Interview Cheat Sheet Q&A

  • What is Xid 79? "Xid 79 occurs when a GPU physically falls off the PCIe bus due to link degradation or hardware failure. Our Python runbook immediately cordons the node in Kubernetes, evicts running pods, and executes an in-band PCIe reset (`nvidia-smi -r`)."
  • What is NVIDIA DCGM? "Data Center GPU Manager interfaces directly with NVML to track SM occupancy %, VRAM temperatures, power draw in Watts, and PCIe error replay counters."
  • How does the Python Backend work? "Built using FastAPI and SQLite (SQLAlchemy ORM), providing high-throughput REST APIs (`/api/v1/telemetry`, `/api/v1/remediate`) with automated audit logging for every self-healing action."
